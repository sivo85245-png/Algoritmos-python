# Análise de Logs de Servidores com Python

## Sobre o projeto
Projeto acadêmico desenvolvido para trabalhar com arquivos de log de servidores e estudar algoritmos de ordenação utilizando Python.

## Tecnologias
- Python
- CSV

## Arquivos
- `aps_final_final.py` — código principal do projeto
- `gerar_logs.py` — script para geração de logs
- `logs_servidor.csv` — dados utilizados no projeto

## Objetivo
Aplicar conceitos de programação, manipulação de dados e algoritmos em um problema prático.
